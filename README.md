Профессиональная внешняя обработка (`.epf`) для массового поиска, интеллектуального масштабирования, конвертации и оптимизации присоединенных изображений номенклатуры в конфигурациях на базе **БСП (Библиотека стандартных подсистем)**.

---

## 📌 Зачем это нужно?

В процессе работы с номенклатурой менеджеры, маркетологи и поставщики загружают фотографии товаров напрямую с камер, смартфонов или фотобанков:
- Разрешения **4K, 8K** и несжатые форматы (**PNG / BMP по 5–25 Мб на одну картинку**).
- База данных 1С быстро разрастается до сотен гигабайт, переполняя диски сервера.
- **Замедляется открытие карточек товаров** и подбор позиций в заказах и РМК.
- **Тормозит обмен с маркетплейсами** (Ozon, Wildberries, Яндекс Маркет) и сайтами (1С-Битрикс), вызывая таймауты выгрузки картинок.
- Резервное копирование (бэкап) базы длится часами.

> **Результат применения обработки:** сокращение объема хранилища изображений в **3–10 раз** (для PNG/BMP — до **25 раз**) без визуальной потери качества для каталога и карточки товара.

## 🌟 Ключевые возможности

### 1. ⚙️ Поддержка всех вариантов хранения файлов БСП
* **Хранение в информационной базе:**
  - Автоматическая поддержка классического хранения в реквизите `ФайлХранилище` справочника `НоменклатураПрисоединенныеФайлы`.
  - Автоматическая поддержка хранения в регистре сведений `РегистрСведений.ДвоичныеДанныеФайлов` (для версий БСП 2.4+).
* **Хранение в томах на диске:**
  - Полная поддержка дисковых томов (`Справочник.ТомаХраненияФайлов`).
  - Прямая корректная перезапись бинарных файлов на сервере/диске с обновлением размера и даты модификации в карточке файла 1С.

### 2. 🎯 Гибкие и точные отборы
* **Папка / подпапка номенклатуры:** выбор группы через штатное дерево групп (`ФормаВыбораГруппы`). Запрос выполняется с условием `В ИЕРАРХИИ`, автоматически захватывая все товары внутри выбранной папки и всех ее подпапок.
* **Отдельный товар:** возможность быстро найти и сжать фото только для одного конкретного артикула.
* **Вид номенклатуры:** фильтрация по категории товара.
* **Порог размера (Кб):** поиск файлов от заданного размера (например, только тяжелее `300 Кб` или `1 Мб`), чтобы не трогать уже оптимизированные картинки.
* **Форматы файлов:** отбор по расширениям (`jpg, jpeg, png, bmp`).
* **Только основное фото:** сжатие только главного изображения карточки (`Номенклатура.ФайлКартинки`) либо всех фотографий из галереи.

### 3. 🛡️ Трехуровневая система безопасности
* **Безопасный тестовый режим (включен по умолчанию):** обработка полностью симулирует сжатие, рассчитывает новый размер, новое разрешение и экономию без физической записи в базу или на диск.
* **Защита от деградации размера:** если после сжатия размер файла увеличился (например, при попытке пережать и без того сильно оптимизированный JPEG), файл **автоматически пропускается**.
* **Резервное копирование оригиналов:** опция выгрузки исходных несжатых картинок в отдельную папку на диске перед их заменой.

### 4. ⚡ Нативный движок Windows WIA (Zero-Install)
* Не требует установки сторонних утилит (ImageMagick, ffmpeg, jpegtran) или внешних DLL.
* Использует аппаратный системный компонент **Windows Image Acquisition Automation** (`WIA.ImageProcess` / `WIA.ImageFile`), присутствующий во всех версиях Windows (начиная с Windows 7 / Server 2008 R2 и до Windows 11 / Server 2025).
* Быстрое и качественное билинейное масштабирование с автоматическим сохранением пропорций (`PreserveAspectRatio = True`).

### 5. 🪄 Автоматическое построение интерфейса (Self-Generating Form)
* **Сборка обработки занимает 60 секунд!** При открытии формы все 15+ реквизитов, команды, 14 колонок таблицы и элементы управления генерируются программно. В Конфигураторе не нужно ничего рисовать вручную.

## ⚡ Сборка за 1 минуту

Подробная пошаговая инструкция доступна в документе [**`Инструкция_по_созданию_EPF.md`**](./Инструкция_по_созданию_EPF.md).

Краткий алгоритм:
1. Запустите **Конфигуратор 1С** → **Файл → Новый → Внешняя обработка**.
2. В свойствах укажите Имя: `СжатиеКартинокНоменклатуры`.
3. Откройте **Модуль объекта** и вставьте код из [**`МодульОбъекта.bsl`**](./МодульОбъекта.bsl).
4. В разделе **Формы** нажмите **Добавить** → сразу нажмите **Готово** (без создания реквизитов!).
5. Откройте вкладку **«Модуль»** созданной формы и вставьте код из [**`МодульФормы.bsl`**](./МодульФормы.bsl).
6. Нажмите `Ctrl + S` и сохраните как `СжатиеКартинокНоменклатуры.epf`.

## 🚀 Варианты использования

### Вариант 1. Запуск через «Файл — Открыть» (рекомендуется для разовых ревизий)
1. В режиме «1С:Предприятие» выберите: **Главное меню → Файл → Открыть...** (`Ctrl + O`).
2. Выберите файл `СжатиеКартинокНоменклатуры.epf`.
3. Подтвердите предупреждение безопасности.

### Вариант 2. Подключение в «Дополнительные отчеты и обработки» (для постоянной работы)
1. Раздел **НСИ и администрирование → Печатные формы, отчеты и обработки → Дополнительные отчеты и обработки**.
2. Нажмите **Добавить из файла...** и укажите `.epf` файл.
3. Обработка автоматически подставит параметры:
   - Вид: *Дополнительная обработка*
   - Безопасный режим: *Отключен* (необходим для работы COM-объекта WIA и доступа к файлам томов).
4. Назначьте быстрый доступ пользователям и нажмите **Записать и закрыть**.

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Безопасно ли сжатие для оригиналов картинок?</b></summary>
Да! Во-первых, по умолчанию включен <b>Тестовый режим</b>, который наглядно показывает расчетный размер каждого файла до реальной записи. Во-вторых, обработка никогда не запишет файл, если его размер после сжатия стал больше оригинала. В-третьих, включив опцию «Создавать бэкап оригиналов», вы можете сохранить все исходники в отдельный каталог на диске.
</details>

<details>
<summary><b>2. Будет ли работать обработка, если картинки хранятся в томах на диске?</b></summary>
Да. Обработка анализирует реквизит <code>ТипХраненияФайла</code> каждого файла. Для томов на диске вычисляется полный путь к файлу (с учетом настроек тома под Windows/Linux), файл на диске безопасно перезаписывается, а в объекте 1С обновляются размер, универсальная дата модификации и расширение.
</details>

<details>
<summary><b>3. Почему не нужно сторонних программ и DLL?</b></summary>
Обработка использует компонент <code>WIA.ImageProcess</code> (Windows Image Acquisition), который входит в состав ОС Windows. Это гарантирует максимальную стабильность, отсутствие конфликтов версий DLL и нулевые требования к установке стороннего софта.
</details>

<details>
<summary><b>4. Как обработать только конкретную группу товаров?</b></summary>
В блоке «1. Отбор файлов» нажмите <code>...</code> в поле <b>«Папка / подпапка»</b>. Откроется дерево групп номенклатуры. Выберите нужную группу — обработка автоматически применит отбор по всей иерархии (включая все вложенные подпапки).
</details>
